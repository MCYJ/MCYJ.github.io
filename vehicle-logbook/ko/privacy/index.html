기기에 보관하는 차량 정보

Vehicle Logbook은 차량 이름, 직접 입력한 계기값, 주유·충전량, 정비, 비용, 단위, 날짜와 메모를 기기에서 처리하도록 설계했습니다. RushLabs는 이 앱의 계정 서비스, 차량 자료 업로드 서비스나 분석 서비스를 운영하지 않습니다. 광고와 자동 경로 수집도 없습니다.

영수증·초안·실행 취소

개발 중인 영수증 기능은 사용자가 선택한 파일의 앱 소유 사본을 보관하며 외부 원본을 수정하지 않습니다. 로컬 기록에는 초안, 가져온 자료의 원문 정보, 실행 취소 이력, 환경설정과 가이드 상태가 포함될 수 있습니다. 개별 기록을 삭제해도 실행 취소 이력이 참조하는 사본은 남을 수 있습니다. 해당 기능의 통합과 검증은 출시 전에 진행합니다.

사용자가 내보내는 파일

백업에는 차량 이력, 비용과 영수증 사본 등 사적인 정보가 포함될 수 있으며 실행 취소에 남은 정보도 포함할 수 있습니다. 암호화된 압축 파일이 아니므로 보관·공유 위치를 직접 선택해 주세요. 사용자가 RushLabs에 보내기로 선택하지 않는 한 당사는 내보낸 파일을 받지 않습니다. 파일 제공자, 공유 대상과 기기 백업에는 각자의 정책이 적용되며 사본이 네트워크로 전송될 수 있습니다.

알림

개발 중인 알림은 RushLabs의 푸시 서버 대신 기기 내 알림을 사용합니다. 거리 기준을 예상하기 위해 위치나 차량 계기값을 자동으로 수집하지 않습니다. 알림 전달은 시스템 권한과 알림 설정에 영향을 받습니다.

복원과 삭제

복원은 로컬 백업을 검증하고 확인을 받은 뒤 현재 원장을 교체하도록 설계했습니다. 삭제 대상은 앱 소유 기록과 사본이며, 개별 삭제한 기록은 실행 취소 참조가 끝날 때까지 남을 수 있습니다. 외부 원본, 이미 공유한 파일과 기기 백업의 사본은 각 보관 위치에서 따로 관리해야 합니다. 정리 대기 상태이면 앱 소유 사본이 일부 남아 있을 수 있습니다.

문의 내용과 웹사이트

RushLabs에 이메일을 보내면 답변을 위해 사용자가 제공한 내용을 이용합니다. 사적인 영수증·백업·비밀번호·신분증은 첨부하지 말아 주세요. 문의 이메일의 삭제를 요청할 수 있습니다. 이 정적 웹사이트에는 광고, 분석 도구, 입력 양식, 외부 글꼴이나 추적 쿠키가 없습니다. 호스팅 제공자는 자체 정책에 따라 접속 정보를 처리할 수 있습니다.
