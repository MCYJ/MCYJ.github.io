이용 가능 여부

Vehicle Logbook은 개발 중이며 현재 공개 다운로드 링크는 없습니다. 영수증 선택, CSV 열 매핑과 알림의 최종 사용 방법은 해당 화면 검증 후 안내합니다.

계산 근거와 함께 소비량 확인

액체 연료 소비량은 완전 주유 사이의 거리와 시작 주유 이후 추가한 연료량으로 계산합니다. 시작 주유량을 다시 더하지 않으며 중간 부분 주유는 구간에 포함합니다. 실제 주유가 빠졌다면 완성된 소비량을 내지 않습니다. 실제 기록 누락과 중복 오입력 삭제는 서로 다른 동작입니다. 요약은 개별 소비율의 단순 평균이 아니라 전체 추가량과 전체 거리로 계산합니다.

단위·에너지·비용 구분

리터, 미국 갤런과 영국 갤런은 서로 다른 단위입니다. 전기는 액체 연료와 별도로 기록하고, 계기판 교체 시에는 구간을 나눕니다. 서로 다른 통화의 비용은 합산하지 않으며 환율을 가져오지 않습니다. 차량 연결로 자동 수집한 값이 아니라 사용자가 입력한 기록을 사용합니다.

전체 백업과 CSV의 차이

로컬 백업은 원장, 참조 중인 영수증 사본, 초안과 실행 취소 이력을 포함하도록 설계했습니다. 복원은 검증과 확인 후 현재 원장을 교체합니다. CSV는 선택한 표 형식 기록이며 첨부와 모든 앱 상태를 담는 전체 백업이 아닙니다. 자료를 교체하기 전에 별도 백업을 보관하세요. 로컬 백업은 암호화 보관함이 아닙니다.

알림과 수동 계기값

알림 화면과 기기 내 알림 전달은 개발 중입니다. 날짜 알림은 시스템 권한과 기기 설정에 영향을 받습니다. 거리 기준은 새 계기값을 입력했을 때만 확인할 수 있으며, 앱이 백그라운드에서 실제 주행거리를 측정하지 않습니다.

문의하기

앱 버전, iOS 버전과 재현 순서를 이메일로 알려주세요. 가져오기 문제라면 열 이름, 숫자 형식과 시간대를 작은 가상 예시로 설명해 주세요. 실제 영수증, 차량 등록 정보, 전체 백업이나 개인 차량 이력은 보내지 않아도 됩니다.
