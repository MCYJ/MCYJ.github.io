Support for Phrase Loop

Open a WAV file

Use a WAV file you have access to on your device. If a file does not open during testing, note its encoding and sample rate when known.

Set your loop points

A marks where the loop begins and B marks where it ends. Choose a short passage and leave a little space on either side of the phrase.

Check microphone access

Recording a take is optional. If recording is unavailable, check the device’s microphone permission for Phrase Loop. Include the device model and system version when reporting a problem.
