워크 레저 지원

작업을 기록하고, 오늘 쓴 시간을 확인하거나 RushLabs에 문의하세요.

작업 시작, 전환, 종료

작업 이름을 입력하고 ‘시작’을 누르세요. 다른 일로 넘어갈 때는 다음 작업 이름을 입력하고 ‘작업 전환’을 누르세요. 이전 작업을 끝낸 시각에 새 작업 기록이 시작됩니다. 일을 마치면 ‘종료’를 누르세요.

오늘 기록 확인

빈 구간은 그 시간에 기록이 없다는 뜻입니다. 완료된 기록을 눌러 시각을 정정하거나, ‘빠진 시간 추가’를 눌러 기록을 추가하세요. 기존 기록과 시간이 겹치거나 기기 시각이 바뀌었다면 기록을 사용하기 전에 시각을 확인하세요.

오늘 기록 CSV 공유

오늘 완료된 기록이 있으면 ‘오늘 기록 CSV 공유’를 누르고 보낼 곳을 선택하세요. 파일에는 완료된 각 기록 중 오늘에 해당하는 구간이 담기며, 원래 시각은 별도 열에 남습니다.

도움이 필요할 때

앱 버전과 iOS 버전, 문제가 발생하기까지의 순서를 알려주세요. 이메일이나 화면 캡처에는 고객사 이름이나 작업 세부 내용을 포함하지 마세요.
