Cut Workbench support

Get help setting up a cutting plan, importing parts, or sharing a report.

Start a plan

Add each sheet with its width, height, edge allowance, and grain direction. Then add the parts you need and set the blade width in millimeters.

Import a CSV parts list

Use the exact header shown below. Enter whole millimeters. For grain, use none, width, or height. For rotate, use true or false. Review any row errors before adding the parts.

name,width_mm,height_mm,quantity,grain,rotate

Check and share your work

Review unplaced parts before cutting. Check off each cut in order and use Share PDF to save or send an A4 report. Measure offsets from the panel edge indicated in the report.
