Quilt Layout Studio support

Edit a block

Tap a block in the preview. Choose which fabric to replace, then select a replacement. Use Edit all repeats to change matching blocks together.

Import a fabric photo

Choose Import fabric photo and select a PNG or JPEG through Files. The project keeps a local copy of the swatch.

Check fabric area

Select Fabric area and set the finished block side in centimetres. Add your seam allowance and cutting waste separately.
