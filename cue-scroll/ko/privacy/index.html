개인정보 처리방침

기기 내 원고 처리

Cue Scroll은 사용자 기기에서 원고를 처리합니다. RushLabs는 원고를 전달받거나 이 앱의 원고 업로드·계정 서비스를 운영하지 않습니다. 앱에는 광고·분석 서비스가 없고 사용자 텍스트를 자동 번역하지 않습니다. 카메라나 마이크 녹음 자료도 수집하지 않습니다.

로컬에 보관하는 자료

앱 소유 저장 공간에는 가져온 텍스트와 원본 파일 사본·이름·편집 원고·큐·읽기 위치·표시와 스크롤 설정·편집 초안·되돌리기·안내 상태가 보관됩니다. 외부에서 선택한 원본은 변경하지 않습니다. 원고 하나를 삭제해도 되돌리기 안에 사본이 남을 수 있으며, 전체 로컬 자료 삭제는 되돌리기와 앱 소유 사본도 대상으로 합니다.

내보내기와 백업

사용자가 내보내기나 백업을 요청하면 로컬 TXT·JSON 사본을 만들고 시스템 공유 창을 엽니다. JSON 백업에는 원본 사본과 초안·되돌리기에 남은 텍스트도 들어 있으며 암호화 파일은 아닙니다. 전송 여부와 대상은 사용자가 선택합니다. 사용자가 직접 보내지 않는 한 RushLabs는 내보낸 파일을 받지 않습니다.

시스템 서비스와 저장 대상

파일 제공 서비스가 사용자가 선택한 클라우드 위치에서 자료를 내려받을 수 있습니다. 공유 대상·기기 백업·클라우드 설정에는 각각의 정책이 적용됩니다. 기기 내 처리라는 설명이 사용자가 내보낸 사본도 기기 밖으로 나갈 수 없다는 뜻은 아닙니다. 이 앱은 원고 목록을 자동 동기화하지 않습니다.

복원과 삭제

복원은 백업을 확인하고 사용자의 동의를 받은 뒤 현재 기록과 초안·되돌리기를 교체하며 목록을 병합하지 않습니다. 앱 소유 자료를 삭제하거나 앱을 제거해도 외부 원본·공유 사본·기기 백업 속 사본까지 삭제되지는 않으므로 각 저장 위치에서 별도로 관리해야 합니다.

문의 이메일과 이 웹사이트

RushLabs에 이메일로 문의하면 사용자가 보낸 정보를 답변에 사용합니다. 개인 원고·백업·비밀번호·신분증은 보내지 마세요. 지원 문의 기록의 삭제는 이메일로 요청할 수 있습니다. 이 정적 웹사이트에는 분석·광고·입력 폼·외부 글꼴·추적 쿠키가 없습니다. 호스팅 제공자는 자체 정책에 따라 연결 정보를 처리할 수 있습니다.
