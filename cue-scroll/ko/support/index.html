원고를 읽고 멈추기

텍스트를 붙여넣거나 파일에서 UTF-8 TXT를 선택하고 큐를 표시한 뒤 읽기 화면을 엽니다. 스크롤 속도·글자 크기·행간을 조절할 수 있습니다. 자동 스크롤은 설정한 속도로 진행하며 음성을 듣고 따라가거나 영상을 촬영하지 않습니다.

읽던 위치로 돌아가기

큐로 이동하면 멈춘 문장을 확인한 뒤 직접 재개합니다. 읽기 위치는 원고의 텍스트에 연결해 화면 배치가 바뀌어도 유지합니다. 파일 열기·공유·편집·설정·중단·재열기 후에도 자동으로 다시 움직이지 않습니다. 미러는 읽기 원고에만 적용하고 조작 버튼은 정상 방향으로 남깁니다. 오른쪽에서 왼쪽으로 읽는 방향은 별도 설정입니다. 편집으로 큐 문장이 바뀌거나 지워졌다면 해당 큐를 확인하고 계속하세요.

사용 한도

원고는 최대 10개, 큐는 원고당 최대 100개입니다. 원고 하나는 사용자가 인식하는 글자 기준 100,000자와 UTF-8 500 KiB를 모두 넘지 않아야 합니다. 현재 작업과 되돌리기에서 참조하는 원본 사본은 합계 5 MiB, 저장 기록 정보는 16 MiB, JSON 백업은 32 MiB까지입니다. 여러 한도가 함께 적용되므로 각 원고의 최대치에 도달하기 전에 전체 저장 한도에 닿을 수 있습니다.1 KiB는 1,024바이트,1 MiB는 1,048,576바이트입니다.

원본·초안·되돌리기

가져온 원본 사본은 UTF-8 BOM이 있으면 이를 포함해 줄바꿈까지 보존합니다. 편집 초안과 최근 10단계 되돌리기를 보관합니다. TXT 내보내기는 현재 편집한 원고의 사본을 만들며 외부 원본을 덮어쓰지 않습니다. 원고 하나를 삭제해도 되돌리기 기록에서 참조하는 동안 사본이 남을 수 있습니다.

백업과 복원

JSON 백업에는 원고·큐·읽기 위치와 설정·편집 초안·되돌리기·참조 원본 사본이 포함됩니다. 자료를 교체하기 전에 별도 백업을 보관하세요. 복원은 파일 검증과 확인 후 현재 로컬 기록 전체를 교체하며 병합하지 않습니다. 백업에는 원문이 들어 있고 암호화 보관함은 아니므로 신뢰할 수 있는 저장 위치를 선택하세요.

삭제와 공유

전체 로컬 자료 삭제는 앱이 관리하는 기록·초안·되돌리기·원본 사본·로컬 내보내기 사본을 대상으로 합니다. 외부 TXT 원본·이미 공유한 사본·기기 백업은 해당 위치에서 별도로 관리해야 합니다. iOS 공유 창에서 직접 선택한 대상으로만 사본을 보내며, 파일 제공 서비스와 공유 대상은 설정에 따라 네트워크를 사용할 수 있습니다.

문의하기

앱 버전·iOS 버전·재현 순서를 이메일로 알려주세요. 개인 원고나 백업을 보내는 대신 언어·길이·파일 크기를 설명해주세요. 지원용 계정은 필요하지 않습니다.
