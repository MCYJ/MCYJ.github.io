Support

Preparing for release

Read and pause

Paste your text or select a UTF-8 TXT file from Files. Add cue points, switch to the reading view and set scroll speed, text size and line spacing. Scrolling follows the speed you set; it does not listen to your voice or record video.

Return to your place

Pause to jump to a cue, check the passage and explicitly resume. Reading positions stay tied to the text across layout changes. Opening files, sharing, editing, settings, interruptions and reopening leave scrolling paused. Mirror mode reverses only the reading text, while controls stay readable. Right-to-left text direction is a separate setting. If an edit changes or removes a cue passage, review the affected cue before continuing.

Limits

Keep up to 10 scripts, with up to 100 cues each. Each script must fit both 100,000 user-perceived characters and 500 KiB of UTF-8 text. Imported originals referenced by current work and undo share a 5 MiB limit; saved record data is limited to 16 MiB and a JSON backup to 32 MiB. These limits apply together, so a collection can reach a storage limit before every script reaches its individual maximum.1 KiB=1,024 bytes;1 MiB=1,048,576 bytes.

Originals, drafts and undo

Imported original copies retain their UTF-8 BOM, when present, and line breaks. Keep an editing draft and up to 10 undo steps. TXT export creates a copy of the current edited script; it does not overwrite the external file you imported. A single-script deletion can remain in undo history until those references expire.

Back up and restore

JSON backup includes scripts, cues, reading positions and settings, editing drafts, undo history and referenced original copies. Save a separate backup before replacing work. Restoring validates the file and asks for confirmation, then replaces all current local records; it does not merge them. A backup contains your text and is not an encrypted vault. Choose a storage location you trust.

Delete and share

The all-local-data deletion action targets app-owned records, drafts, undo, original copies and local export copies. External TXT originals, files already shared and device backups must be managed separately. The iOS share sheet sends a copy only to the destination you select. Files providers and sharing destinations may use the network according to your settings.

Get help

Email your app version, iOS version and reproduction steps. Describe the language, length and file size instead of sending private scripts or backups. You do not need a support account.
