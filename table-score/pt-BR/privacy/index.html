Table Score · Política de privacidade

O Table Score guarda no seu dispositivo o nome do jogo, os nomes dos jogadores, as pontuações e os motivos das correções. O app não exige uma conta e não envia esses dados à RushLabs.

Ao compartilhar um backup, você escolhe o destino no menu do iOS. A pessoa ou o serviço que receber o arquivo pode guardar uma cópia.

Para apagar os dados locais, apague o app e seus dados do dispositivo. A opção que remove o app mantendo documentos e dados não apaga a planilha de pontos. Os backups do sistema podem guardar dados conforme suas configurações. Apague separadamente os arquivos exportados.

Se escrever para a RushLabs, usaremos seu endereço de email e as informações enviadas para responder. Você pode pedir a exclusão dessas informações escrevendo para o mesmo endereço.
