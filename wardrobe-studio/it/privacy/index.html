Wardrobe Studio · Privacy

Wardrobe Studio conserva sul dispositivo le foto scelte, gli eventuali ritagli, i nomi dei capi, le categorie, il look e la cronologia degli utilizzi. La rimozione dello sfondo avviene sul dispositivo. L’app non richiede un account e non invia automaticamente il contenuto del guardaroba a RushLabs.

Quando condividi un backup, scegli la destinazione nel foglio di condivisione di iOS. Il file contiene i dati del guardaroba e le foto: il destinatario o il servizio scelto può conservarne una copia.

Il ripristino di un backup sostituisce i dati attualmente salvati nell’app. Per rimuovere i dati locali, elimina l’app. Le copie di backup del sistema possono conservare dei dati secondo le tue impostazioni; elimina separatamente i file di backup esportati.

Se contatti RushLabs via e-mail, il tuo indirizzo e le informazioni che invii vengono usati per rispondere alla richiesta. Puoi richiederne la cancellazione scrivendo allo stesso indirizzo. Non inviare foto personali non necessarie.
