Wardrobe Studio · Politique de confidentialité

Wardrobe Studio conserve sur l’appareil les photos choisies, les images détourées, les noms, les catégories, les tenues et l’historique. Le détourage s’effectue sur l’appareil. L’app ne requiert aucun compte et n’envoie pas le contenu de votre garde-robe à RushLabs.

Lorsque vous partagez une sauvegarde, vous choisissez la destination dans iOS. Le destinataire ou le service choisi peut conserver le fichier.

Pour supprimer les données locales, supprimez l’app. Les sauvegardes du système peuvent conserver certaines données selon vos réglages. Supprimez séparément les fichiers de sauvegarde que vous avez exportés.

Si vous contactez RushLabs, votre adresse e-mail et les informations envoyées servent à vous répondre. Vous pouvez demander leur suppression en écrivant à la même adresse.
