Home Rhythm support

Get help with your rooms, chores, and cleaning sessions.

Start a session

  1. Add a room, then add a chore with an estimated duration and repeat interval.
  2. Choose 5, 15, or 30 minutes under Today’s Session and select Suggest due tasks. You can also add chores from a room yourself.
  3. Start the session and mark each chore complete. If you finish the wrong chore, use Undo last completion.
