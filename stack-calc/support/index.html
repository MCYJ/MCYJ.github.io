STACK CALC

Support

01

Start with RPN

For 2 + 3, enter 2, tap Enter, enter 3, then tap +. An operation consumes the current entry once. Enter with no active entry duplicates X. General numbers and Scientific still use RPN; Fixed word adds bounded bit-pattern arithmetic. The three-step guide uses a separate example session and returns to your own work.

02

Precision, word settings and units

Integers use exact integer arithmetic within resource limits. Decimal/scientific results use approximate binary64 values; the app does not promise arbitrary precision. A large integer may require an explicit approximate-conversion confirmation. Word mode offers 8/16/32/64 bits and BIN/OCT/DEC/HEX, with signed interpretation and overflow shown. Length, mass, time and temperature conversions are local. Temperature points and temperature differences are different choices. These are calculations, not measurements.

03

Input and capacity

The stack holds up to 64 values, raw entry up to 1,024 UTF-16 code units and the tape up to 500 successful commands. Very large numbers and documents have additional resource limits. Input accepts supported regional decimal forms; grouping separators are not guessed. A rejected operation keeps the entry and working records. Presets hold up to 100 active items and up to 100 commands each, with 10 preset-edit undo steps.

04

Browse, apply, undo

Selecting a tape row is read-only. Apply changes the working cursor after confirmation, within the available 100-step calculation undo window. Later steps remain redo until a successful new command replaces that branch. Older rows can still be inspected. User entries and preset names are not automatically translated when the interface language changes.

05

Start a new tape without discarding the old one

At 500 commands, raw entry can still be saved; the tape is not silently shortened. Back up and start a new tape first saves the same old tape and current raw entry on the device, validates a full backup, and opens system sharing. Only after sharing completes and you separately confirm does the app start an empty tape, keeping the current stack, mode, word settings, angle, entry and presets. Sharing cancellation or failure does not reset the old tape. Keep the exported copy.

06

Backup, restore and recovery

The plain JSON backup includes the calculation session, raw entry, tape/cursor and presets with their retained history. Interface language and guide preferences are separate settings. Restore validates the chosen file and asks before replacing the current calculation book; it does not modify that external original. If the working book cannot be opened, recovery can retain a verified app-owned copy of the damaged original before replacement. Retained safety copies are different from cleanup failures and have a separate removal action.

07

Deletion and cleanup

Delete all app records clears the calculation book and presets and requests removal of app-owned completed exports and recovery copies. A pending cleanup message means some owned files remain: use Retry cleanup. Normal cleanup does not remove deliberately retained safety copies. Language and guide preferences may remain. Files already shared, external originals and system/device backups must be managed separately; uninstalling the app does not delete those external copies.

08

Contact support

Email the app version, iOS version, selected mode/word width/radix/angle, and steps using invented numbers. Do not send a full private backup or confidential calculation history. This page will be updated when a public download is available.
