02

기기에 저장하는 자료

입력 원문, 정확한 정수와 근사값, 계산 명령, 모드·비트·각도 설정, 기록과 실행 취소 상태, 프리셋 이름·명령·이력, 언어와 가이드 상태를 앱 소유 로컬 공간에 저장합니다. RushLabs는 이 앱의 계정·계산 업로드·광고·분석 서비스를 운영하지 않습니다. 사용자가 입력한 내용은 자동 번역하거나 번역 서비스로 보내지 않습니다.

03

사용자가 고르는 파일

복원은 Files에서 선택한 백업을 읽고 검증한 뒤 현재 자료를 대체합니다. 외부 원본은 편집하지 않습니다. 복구 과정에서 손상 원본의 앱 소유 안전 사본을 보관할 수 있으며, 정리 실패 시 임시 작업 파일이 남을 수 있습니다. 의도적으로 보관한 사본은 명시적으로 제거할 수 있고 일반 정리 재시도로 지우지 않습니다.

04

일반 텍스트 백업과 공유

JSON 백업은 읽을 수 있는 일반 텍스트이며 암호화 보관함이 아닙니다. 개인 입력과 과거 값·명령·프리셋 및 보관 중인 실행 취소 정보가 포함될 수 있습니다. 완료된 내보내기 캐시는 일반적으로 현재 묶음과 이전 묶음만 보관하며 공유 중인 파일은 유지합니다. 공유 대상을 사용자가 선택하고, 사용자 의사로 보내는 경우에만 RushLabs가 사본을 받습니다. Files 제공자와 공유 대상은 자체 정책에 따라 사본을 업로드할 수 있습니다.

05

삭제와 남아 있는 사본

프리셋을 삭제해도 이전 내용이 프리셋 실행 취소 이력에 남을 수 있습니다. 앱 기록 전체 삭제는 계산 자료를 초기화하고 앱 소유 내보내기·복구 사본의 제거를 요청합니다. 정리 대기는 요청한 파일 삭제가 끝나지 않았다는 뜻입니다. 언어·가이드 설정은 남을 수 있으며 앱 삭제 시 앱 소유 자료는 iOS 동작에 따라 제거됩니다. 외부 원본·공유한 사본·기기 백업은 별도 자료이므로 각 위치에서 관리해야 합니다.

06

시스템 서비스와 문의 이메일

iOS 백업·시스템 진단·Files 제공자·공유 서비스는 각 설정과 정책을 따릅니다. RushLabs에 이메일을 보내면 문의에 답변하기 위해 사용자가 제공한 내용을 사용하며 이메일로 해당 대화의 삭제를 요청할 수 있습니다. 비공개 백업·비밀번호·신분 서류는 포함하지 마세요.

07

이 웹사이트

이 정적 페이지에는 분석 스크립트·광고·입력 폼·외부 글꼴·추적 쿠키가 없습니다. 이메일 링크는 사용자의 이메일 앱을 엽니다. 호스팅 제공자는 자체 정책에 따라 연결 정보를 처리할 수 있습니다. 이 웹사이트를 통해 계산 자료를 제출하지 않습니다.
