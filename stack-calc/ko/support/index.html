STACK CALC

지원

01

RPN으로 시작하기

2 + 3은 2 입력 → 입력 확정 → 3 입력 → + 순서입니다. 연산은 입력 중인 값을 한 번 반영합니다. 입력이 비어 있을 때 입력 확정을 누르면 X를 복제합니다. 일반 수와 과학 계산도 RPN 방식이며, 고정 비트는 폭이 정해진 비트 패턴 연산을 제공합니다. 3단계 가이드는 별도 예제 세션을 사용하고 개인 작업으로 돌아옵니다.

02

정밀도·비트 설정·단위

정수는 자원 한도 안에서 정확한 정수 연산을 사용합니다. 소수와 과학 함수 결과는 binary64 근사값이며 임의 정밀도를 보장하지 않습니다. 큰 정수를 근사값으로 바꾸려면 별도 확인이 필요할 수 있습니다. 고정 비트는 8·16·32·64비트와 BIN/OCT/DEC/HEX를 제공하며 부호 해석과 overflow를 표시합니다. 길이·질량·시간·온도 변환은 로컬 계산입니다. 점온도와 온도 차이는 구분하며 실제 값을 측정하는 기능은 아닙니다.

03

입력과 용량

스택은 최대 64개 값, 입력 원문은 UTF-16 코드 단위 최대 1,024개, 계산 기록은 성공한 명령 최대 500개입니다. 매우 큰 수와 문서에는 추가 자원 한도가 있습니다. 지원되는 지역별 소수 표기는 인식하지만 자릿수 구분 기호를 추측하지 않습니다. 거부된 연산은 입력과 작업 기록을 유지합니다. 활성 프리셋은 최대 100개, 프리셋당 명령은 최대 100개이며 프리셋 편집 실행 취소는 10단계입니다.

04

살펴보기·적용·실행 취소

기록의 행을 선택하는 것은 읽기 전용입니다. 적용은 별도 확인 후 사용 가능한 계산 실행 취소 100단계 범위에서 작업 위치를 바꿉니다. 이후 단계는 성공한 새 명령이 분기를 대체하기 전까지 다시 실행할 수 있습니다. 더 오래된 행도 살펴볼 수 있습니다. 인터페이스 언어를 바꿔도 입력 원문과 프리셋 이름은 자동 번역하지 않습니다.

05

이전 기록을 버리지 않고 새 기록 시작하기

명령 500개에 도달해도 입력 원문은 저장할 수 있으며 기록을 조용히 줄이지 않습니다. 백업 후 새 기록 시작은 먼저 같은 이전 기록과 현재 입력 원문을 기기에 저장하고 전체 백업을 검증한 뒤 시스템 공유를 엽니다. 공유를 완료하고 사용자가 별도로 확인해야 새 빈 기록을 시작합니다. 현재 스택·모드·비트 설정·각도·입력·프리셋은 유지합니다. 공유 취소나 실패 시 이전 기록은 초기화하지 않습니다. 내보낸 사본을 보관하세요.

06

백업·복원·복구

일반 JSON 백업에는 계산 세션, 입력 원문, 기록과 작업 위치, 프리셋 및 보관 중인 이력이 포함됩니다. 언어와 가이드 설정은 별도입니다. 복원은 선택한 파일을 검증하고 현재 계산 자료를 대체하기 전에 확인을 받으며 외부 원본을 수정하지 않습니다. 작업 자료가 열리지 않으면 손상된 원본의 검증된 앱 소유 사본을 보관한 뒤 복구할 수 있습니다. 의도적으로 보관한 안전 사본은 정리 실패와 다르며 별도로 제거할 수 있습니다.

07

삭제와 정리 대기

앱 기록 전체 삭제는 계산 자료와 프리셋을 비우고 앱이 소유한 완료된 내보내기 파일과 복구 사본의 제거를 요청합니다. 정리 대기 표시는 일부 소유 파일이 남았다는 뜻이므로 정리 재시도를 사용하세요. 일반 정리 재시도는 의도적으로 보관한 안전 사본을 지우지 않습니다. 언어와 가이드 설정은 남을 수 있습니다. 공유한 사본·외부 원본·시스템 또는 기기 백업은 각 위치에서 따로 관리해야 하며 앱 삭제로 외부 사본이 지워지지는 않습니다.
