RPN · 과학 계산 · 고정 비트

계산 순서가 남는 작업대.

입력 원문, 스택의 값, 계산 과정을 함께 확인하세요. RPN 계산과 과학 함수, 고정 폭 비트 도구를 기기 안에서 사용합니다.

RPN 사용 예시

X5
2 ENTER 3 + → X = 5

첫 값을 확정하고 두 번째 값을 입력한 뒤 연산을 선택합니다.

01

값의 의미를 구분하세요

정확한 정수와 근사 실수를 따로 표시합니다. 8·16·32·64비트 패턴과 부호 해석을 확인하고, 진법과 각도 설정을 보면서 계산합니다.

02

결과까지의 과정을 확인하세요

성공한 명령을 최대 500개 보관합니다. 기록의 한 단계를 선택해 살펴보는 동작과 작업 스택에 적용하는 동작을 구분합니다. 계산 실행 취소는 최대 100단계이며, 성공한 새 명령은 다시 실행할 분기를 대체할 수 있습니다.

03

계정 대신 작업을 보관하세요

계산과 프리셋은 기기에 저장합니다. 일반 JSON 백업을 시스템 공유 화면으로 내보낼 수 있습니다. RushLabs 계정, 광고, 구독, 분석 서비스는 없습니다.
